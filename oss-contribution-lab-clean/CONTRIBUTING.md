# Contributing

이 프로젝트는 오픈소스 기여를 처음 경험하는 사람의 참여를 환영합니다.

## 기여 절차

1. 해결하고 싶은 Issue를 확인합니다.
2. 저장소를 Fork합니다.
3. 작업용 Branch를 생성합니다.
4. 변경사항과 테스트를 작성합니다.
5. 명확한 Commit 메시지를 작성합니다.
6. Pull Request를 생성하고 변경 이유와 확인 방법을 설명합니다.
7. Review 의견이 있으면 반영한 뒤 다시 검토를 요청합니다.

## 권장 Branch 이름

- `docs/...`
- `fix/...`
- `feat/...`
- `test/...`

## Pull Request 원칙

- 한 PR에는 가능한 한 하나의 목적만 담아주세요.
- 동작이 변경되면 테스트를 함께 추가해주세요.
- 관련 Issue가 있다면 PR 본문에 연결해주세요.
- 자동 생성된 대규모 변경보다 작고 검토 가능한 변경을 선호합니다.
